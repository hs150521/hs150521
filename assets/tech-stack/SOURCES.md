# Tech stack badges

All badges are SVG files generated by Shields.io with style=for-the-badge, a white logo, a brand-palette background, and a native height of 28px. They are stored locally so they do not require a live badge service at view time.

Python, C++, Java (OpenJDK), Qt, Unity, Arduino, DaVinci Resolve and OBS use Shields.io built-in icons. Other badges pass custom white SVG icons to Shields.io. Adobe badges use the application glyphs without the colored square. WPILib and JLCEDA use their wordmark symbols; ATEM uses the Blackmagic Design manufacturer symbol.
